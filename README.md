# Brightdesk Wiki

The official knowledge centre for the Brightdesk Office Suite.

The wiki helps customers find the right product, learn how to use it, understand what is available, and solve common problems. Developer and maintainer documentation is kept in a separate section.

## The ten Brightdesk products

Pages · Sheets · Decks · Notes · Database · Forms · Lists · Planner · To Do · Workspace

These are the only approved customer products. Brightdesk-AI is internal engineering/tooling, not an additional customer product.

## Documentation principles

- Write in plain, direct English.
- Give users practical examples and clear, numbered steps.
- Separate customer guides from technical documentation.
- Label content as verified, source-confirmed, planned, under test or not available.
- Do not present design artwork as a screenshot or a configured package as a verified release.
- Keep pages aligned with current source code, tests and approved product decisions.
- Never publish credentials, private prompts or internal-only material.

See [Documentation standards](docs/documentation-standards.md) before contributing. Request a missing guide or report a documentation problem through [GitHub Issues](https://github.com/conz20/Brightdesk-Wiki/issues).

## Current implementation status

The repository is being built as a Markdown-first knowledge base. A polished searchable website, publishing pipeline and automated cross-repository freshness checks are future implementation work; they are not claimed to exist yet.
