# How to use this wiki

This wiki is organised around the question you are trying to answer. You do not need to know a technical term before you start.

## Start with what you want to do

| If you are trying to… | Look for… |
| --- | --- |
| Choose a Brightdesk product | [Product directory](products/README.md) |
| Learn a task from beginning to end | [How-to guides](guides/README.md) |
| Understand a button, setting or term | The relevant product guide or [glossary](glossary.md) |
| Fix an error or unexpected result | [Troubleshooting](help/README.md) |
| Understand where your work is stored | [Privacy and data](privacy/README.md) |
| Install or update Brightdesk | Installation and update guides (published only after release steps are verified) |

## Examples

**Example 1: “I need to write a letter.”**

1. Open the [Pages guide](products/pages.md).
2. Find the section for creating a document.
3. Follow the numbered steps in order.
4. If the screen looks different, check the guide's version and status before continuing.

**Example 2: “My spreadsheet calculation is wrong.”**

1. Open the [Sheets guide](products/sheets.md).
2. Look for formulas and calculations.
3. If the result still looks wrong, use the troubleshooting guide and include the exact error message when asking for help.

**Example 3: “I don't know which product I need.”**

Start with [What is Brightdesk?](getting-started/what-is-brightdesk.md), then use the product directory to compare the ten products.

## How instructions are written

- Steps use numbered lists when order matters.
- Button names appear in **bold** and should match the real interface.
- A note explains useful extra information.
- A warning identifies something that could cause lost work, an unexpected change or a security problem.
- Screenshots show the real product only after the workflow has been checked. Proposed interface artwork is labelled as artwork.

## If you cannot find an answer

The guide may not exist yet, or the feature may still be under development. Visit [Brightdesk Wiki issues](https://github.com/conz20/Brightdesk-Wiki/issues) and request the exact guide you need. Include the product name, what you were trying to do and what happened. Do not include passwords, private documents or other sensitive information.
