# Languages and spelling

Brightdesk separates the language used by its menus from the language used to check your writing. You can choose these separately.

Display-language packs and spelling dictionaries are obtained through the official Brightdesk language controls. Do not download dictionary files from third-party sites.

## Open the language controls

1. Open Brightdesk Suite.
2. Select the **Settings** cogwheel in the top-right corner.
3. Choose **Languages & dictionaries**.

## Change the display language

1. Find **Display language**.
2. Choose a language that appears under the installed languages.
3. To add another one, find it under **Available language packs** and choose **Install**.
4. When the pack appears under **Installed language packs**, select it as the display language.

The display language changes Brightdesk menus, labels and messages. The change applies straight away.

## Choose a proofing language

The proofing language is separate from the display language. It tells the spelling checker which language to use for the open document.

1. Find **Proofing language**.
2. Choose the language you want to check.
3. Read the status shown beside the selection. Availability can depend on the installed resources and your operating system.

## Install a spelling dictionary

1. Find **Available spelling dictionaries**.
2. Search for the language or region you need.
3. Choose **Install** beside the matching dictionary.
4. Check that it appears under **Installed spelling dictionaries**.

Only use the official Brightdesk catalogue and update route. A language name being visible in a menu does not, by itself, mean its spelling dictionary is installed.

## Check spelling in a document

Spelling checks are available for open Pages, Sheets, Decks and Notes documents where the required dictionary is installed.

1. Open the document in its product.
2. Return to **Settings → Languages & dictionaries** if you need to change the proofing language.
3. Under **Check the current document**, choose an installed dictionary.
4. Select **Check spelling**.
5. Review the possible spelling issues and suggestions.

The spelling check reports suggestions. It does not rewrite or change your document automatically.

## When a dictionary is unavailable

**The language appears, but spelling is not available.** Check whether the matching item appears under **Installed spelling dictionaries**. If it is only in the available catalogue, install it first.

**The proofing status says no dictionary.** Choose a language with an installed dictionary or install the required official dictionary pack.

**The menus changed, but spelling did not.** Display language and proofing language are separate settings. Choose the proofing language as well.

**The language is not listed.** Check the official Brightdesk language catalogue again when connected to the approved language-resource service. Do not substitute an unrelated dictionary download.

## Technical detail

Language packs provide interface translations. Spelling dictionaries provide proofing data. They are different resources and may have different availability. See [Technical Documentation](../technical/index.html) for system and data-boundary information.
