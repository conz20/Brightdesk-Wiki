# Install and update Brightdesk

This guide covers the Brightdesk Suite installer and the current update process. Pages, Sheets, Decks, Notes, Database, Forms, Lists, Planner, To Do and Workspace are managed as product workspaces inside the Suite. Use the Suite's product controls to add or remove workspaces; do not look for a separate installer for each workspace.

## Before you install

1. Use only an official Brightdesk Suite installer published for your operating system.
2. Install only a release that Brightdesk has marked as verified for your computer.
3. Open the installer and follow the instructions shown by Windows, macOS or Linux.
4. You do not need to install Node.js or use Terminal or Command Prompt to run Brightdesk.
5. Read the Brightdesk Terms and Conditions when they appear.

Choose **Accept** or **Agree** to continue. Choosing **Decline** or **Disagree**, or closing the required agreement without accepting, prevents the product workspace from opening.

A configured installer format does not by itself mean that a verified download is available. Do not use an installer copied from an unofficial website or file-sharing service.

## Add or remove products after installation

1. Open Brightdesk Suite.
2. Select **Apps** in the left navigation.
3. Find the product you want.
4. Choose **Add to Suite** to make an available workspace part of your Suite.
5. To remove a workspace from the Suite, choose **Remove from Suite** and read the confirmation message.

Removing a workspace from the Suite is not the same as deleting its local project files.

## Updates

Brightdesk may show official update notices when they are available. The current Suite does not yet have a configured update-publishing provider, so live update delivery is **not active or verified**. Do not expect an update download or automatic update check to be available yet. Do not use a third-party update site.

## Repair and recovery

A repair procedure has not yet been verified for the current Brightdesk Suite release. Do not choose **Remove**, delete product folders or delete local project files as a repair attempt. Use only repair instructions supplied with an official Brightdesk release after that procedure has been checked for your operating system.

## Common questions

**Do I install Pages, Sheets or Decks separately?** These are workspaces you add or remove inside Brightdesk Suite. Use the Suite's **Apps** area.

**Can I update Brightdesk right now?** Live update delivery is not active or verified yet.

**Where do I find the steps for a particular product?** Open [Everyday Help](index.html), choose one of the ten products, then follow its task guide.
