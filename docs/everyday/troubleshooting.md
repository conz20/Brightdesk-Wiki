# Troubleshooting Brightdesk

Start with the product or part of Brightdesk that is giving you trouble. Each product guide includes common questions and known boundaries.

## Before you change anything

1. Read the message on screen and note which product is open.
2. Save your current project when the product still allows you to do so.
3. Check that you are using a supported file type.
4. Use the matching product guide below.
5. Do not delete project files, reset folders or choose **Remove** as a repair attempt.

## Common Suite questions

**An installer or update is not available.** Read [Install and update Brightdesk](install-update.html). Live update delivery is not active or verified yet.

**A spelling dictionary is missing.** Read [Languages and spelling](languages-and-spelling.html), then check the installed dictionary list and proofing-language status.

**You cannot find a product workspace.** Open **Apps** in Brightdesk Suite and check whether the product is marked **Available to add** or **In your Suite**. See [Get started with Brightdesk Suite](../customer-start-here.html).
