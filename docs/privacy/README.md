# Privacy and data

Brightdesk is designed as a local-first desktop suite. Customer documentation must explain data handling plainly and accurately.

## Topics

- [Local-first overview](local-first.md)
- Where product data is stored
- Backups and recovery
- Internet connections and update checks
- What information Brightdesk does and does not send

## Important distinction

A product being local-first does not prove that every feature is offline. Explain each network-related feature separately, including its purpose and the information it exchanges. Never claim that customer content is uploaded, synced or shared unless the implementation and approved product policy explicitly say so.
