# Help and troubleshooting

Start with the product you are using and the result you expected.

## Before you ask for help

1. Write down the product name.
2. Note your operating system and Brightdesk version, if known.
3. Copy the exact error message.
4. Describe what you clicked immediately before the problem.
5. Say what happened instead of what you expected.

Do not send passwords, private documents, licence secrets, access tokens or other sensitive information.

## Troubleshooting topics to build

- Brightdesk will not open
- A product closes unexpectedly
- A file will not open or save
- A change does not appear
- An update check or download fails
- A product behaves differently after an update

These topics are a guide plan. Publish fixes only after the cause and solution have been verified. If a problem could risk data loss, tell the reader to stop and preserve a copy of their files before trying destructive steps.
