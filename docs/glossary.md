# Glossary

| Term | Plain-English meaning |
| --- | --- |
| **Local-first** | Designed so your work is kept on your device; individual online features must still be explained separately. |
| **Product** | One of the ten Brightdesk customer tools: Pages, Sheets, Decks, Notes, Database, Forms, Lists, Planner, To Do or Workspace. |
| **Suite** | The Brightdesk desktop experience that brings the ten products together. |
| **Verified** | Checked against a named implementation, test or running product, with evidence and a date. |
| **Interface design artwork** | A picture showing an intended design. It is not a screenshot of a running product. |
