# Start here: find the Brightdesk help you need

This page is for anyone who wants to use Brightdesk but is not sure where to look. Start with the thing you want to do, not a technical term.

## Choose the right product

| What are you trying to do? | Start with |
| --- | --- |
| Write a letter, report or other document | [Pages](products/pages.md) |
| Work with spreadsheet data or calculations | [Sheets](products/sheets.md) |
| Make or present slides | [Decks](products/decks.md) |
| Capture notes and ideas | [Notes](products/notes.md) |
| Keep structured tables and records | [Database](products/database.md) |
| Create questions and collect responses on this device | [Forms](products/forms.md) |
| Track items in a structured list | [Lists](products/lists.md) |
| Organise a project plan and its tasks | [Planner](products/planner.md) |
| Keep track of personal tasks and due dates | [To Do](products/to-do.md) |
| Bring project information together | [Workspace](products/workspace.md) |

These are product-purpose descriptions, not a promise that every workflow is already released. Each guide must say what has actually been verified.

## Examples: where should I look?

**“I want to create a report.”** Open Pages. Look for a guide about creating documents. If that step-by-step guide is not present yet, the wiki should say so rather than invent button names.

**“I want to collect answers from a form.”** Open Forms. Check the current guide for the question types and response workflow that have been verified. The product's first-version scope describes local response collection; do not assume that public links or cloud responses are available.

**“I cannot find a feature I expected.”** Check the product's current scope and status. A feature labelled Planned or Not available should not be followed as if it were already in the product.

## Understand the guide labels

| Label | What it tells you |
| --- | --- |
| **Verified** | The steps were tested in the named product version and operating system. |
| **Source-confirmed** | The current repository describes the feature, but the complete user workflow has not been tested. |
| **Planned** | It is intended for later; it is not available guidance. |
| **Under test** | Work exists, but testing is not complete. |
| **Not available** | The current product scope does not include it. |
| **Needs review** | The source changed or the page may be out of date. |

## If the answer is missing

Request a guide through [Brightdesk Wiki issues](https://github.com/conz20/Brightdesk-Wiki/issues). Include:
- Which product you are using.
- What you want to achieve.
- What you tried.
- What happened instead.
- Your product version and operating system, if known.

Do not include passwords, access tokens, private documents or customer data.

## What a good Brightdesk guide should look like

A complete guide has:
1. A clear title that matches the user's question.
2. A short explanation of what the steps will achieve.
3. Any requirements the user needs before starting.
4. Numbered steps using the exact visible button and menu names.
5. An example with fictional information.
6. The result the user should expect to see.
7. Safe troubleshooting advice.
8. A product version, operating system and verification date.

The wiki must never describe a design mock-up as a screenshot or an untested feature as verified.
