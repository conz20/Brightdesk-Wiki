# Start here: find the Brightdesk help you need

> **Availability:** This guide is draft content in the private Wiki source. It is not yet available from a public help website or installed product.

Start with what you want to do. You do not need to know a technical term.

## Choose the right product

| What are you trying to do? | Start with |
| --- | --- |
| Write a letter, report or other document | [Pages](products/pages.html) |
| Work with spreadsheet data or calculations | [Sheets](products/sheets.html) |
| Make or present slides | [Decks](products/decks.html) |
| Capture notes and ideas | [Notes](products/notes.html) |
| Keep structured tables and records | [Database](products/database.html) |
| Create a form or review its responses | [Forms](products/forms.html) |
| Track items in a structured list | [Lists](products/lists.html) |
| Organise a project plan and its tasks | [Planner](products/planner.html) |
| Keep track of personal tasks and due dates | [To Do](products/to-do.html) |
| Bring project information together | [Workspace](products/workspace.html) |

These descriptions help you choose a product. They are not a promise that every workflow is already available.

## Understand the guide labels

| Label | What it tells you |
| --- | --- |
| **Verified** | The steps were run in the named product version and operating system. |
| **Source-confirmed** | Current implementation or tests support the feature, but the complete user workflow has not been tested. |
| **Planned** | The feature is intended for later and is not available guidance. |
| **Under test** | Work exists, but testing is not complete. |
| **Not available** | The current product scope does not include it. |
| **Needs review** | The page has not yet been checked against a current end-to-end workflow or may be out of date. |

## What to do when a guide is missing

A public guide-request or support contact has not been published yet. Do not send passwords, private documents, customer data or access tokens through public websites. This help site will link a customer-safe request route when one is approved.

## What a complete guide should contain

A useful step-by-step guide should include the exact product version and operating system, the visible button and menu names, numbered instructions, a fictional example, the expected result and safe troubleshooting steps. A design mock-up is never presented as a real screenshot, and an untested feature is never described as verified.
