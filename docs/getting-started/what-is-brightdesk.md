# What is Brightdesk?

Brightdesk is an independent, local-first desktop productivity suite. It brings together ten focused products with one consistent Brightdesk experience.

Brightdesk is its own product family. It is not affiliated with Microsoft, Adobe or ArtCraft.

## The ten products

| Product | What it helps you do |
| --- | --- |
| [Pages](../products/pages.md) | Create and format documents, letters and reports. |
| [Sheets](../products/sheets.md) | Work with spreadsheets, formulas, calculations and data. |
| [Decks](../products/decks.md) | Create, edit and present slide presentations. |
| [Notes](../products/notes.md) | Capture and organise notes and ideas. |
| [Database](../products/database.md) | Build local tables, define fields and manage records. |
| [Forms](../products/forms.md) | Create forms, preview questions and collect responses locally. |
| [Lists](../products/lists.md) | Organise records with custom columns, search, filters and sorting. |
| [Planner](../products/planner.md) | Organise plans, buckets, tasks, priorities and progress. |
| [To Do](../products/to-do.md) | Manage personal tasks, due dates and daily priorities. |
| [Workspace](../products/workspace.md) | Bring project pages, notes, checklists and information together. |

These are the ten approved customer products. Brightdesk-AI is an internal engineering/tooling project, not an eleventh customer product.

## What does local-first mean?

Brightdesk is designed around work kept on your device. Product documentation must explain clearly when a feature uses the internet and what it does. Do not assume that a feature uploads, syncs or shares customer content.

## Which product should I open?

- Writing a letter or report? Start with **Pages**.
- Working with calculations or tabular data? Start with **Sheets**.
- Preparing slides? Start with **Decks**.
- Capturing thoughts? Start with **Notes**.
- Keeping structured records? Start with **Database** or **Lists**.
- Collecting answers on this device? Start with **Forms**.
- Organising a project? Start with **Planner** or **Workspace**.
- Managing your personal tasks? Start with **To Do**.

These are starting suggestions, not a claim that every possible workflow is already implemented. Check each product guide for the current verified feature list.

## Important

Brightdesk is desktop software. Do not describe a mobile edition as available unless a future release is explicitly verified and documented.
