# Technical detail

This is the more detailed side of Brightdesk Help. It is for people who are comfortable with technology, want to understand more, or need extra context before choosing a workflow.

You do not need to read these pages to use Brightdesk. If you just want to complete an everyday task, use the simpler [Everyday Help guides](../index.html).

## What these pages cover

These guides explain the behaviour that is supported by current product source and documentation. They are not API references, promises of unimplemented features, or a substitute for testing a particular release.

Each product guide remains marked **Needs review** until its documented workflows have been completed in a current installed desktop build. Source-level explanations are useful context, but they do not prove that a released build behaves identically.
