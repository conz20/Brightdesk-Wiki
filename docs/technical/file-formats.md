# File formats

This reference lists the file types currently described by the Suite's open-file and product export routes. A file extension identifies the format; renaming a file does not convert its contents.

## Open-file routing

| File extension | Opens in | Notes |
| --- | --- | --- |
| .bdesk | Brightdesk project | Reopens a saved Brightdesk project |
| .docx | Pages | Word document input |
| .md, .html | Pages | Text or HTML document input |
| .xlsx, .xlsm | Sheets | Spreadsheet input |
| .csv, .tsv | Sheets | Delimited tabular data |
| .pptx | Decks | Presentation input |
| .txt | Notes | Plain-text input |

## Export routes

| Product | Available export |
| --- | --- |
| Pages | DOCX or HTML; PDF is available through Suite Home → PDF |
| Sheets | XLSX or CSV |
| Decks | PPTX |
| Notes | Markdown or plain text |
| Database | CSV |

Export creates a separate file. Keep a Brightdesk project copy when you need to reopen the work in Brightdesk.

## Compatibility limits

- A supported extension confirms that Brightdesk has an open or export route for that format. It does not guarantee that every feature from another application has an equivalent representation.
- Do not rename a file extension to try to convert a file.
- Check the current product guide for the exact controls and available export options.
- Formats not listed here should not be treated as supported.
