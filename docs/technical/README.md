# Technical documentation

This section is for developers and maintainers. It is separate from customer-facing instructions.

## Topics

- Repository map and ownership
- Architecture and shared foundations
- Build and test instructions
- API and compatibility references
- Release and packaging procedures
- Security and dependency notices
- Engineering decisions

Technical pages must link to the source repository, file, test or decision they describe. Include the exact tool version and command where relevant. Mark platform-specific checks clearly; a passing build on one operating system is not proof of support on another.
