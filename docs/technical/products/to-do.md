# To Do technical reference

To Do is Brightdesk's personal task workspace.

## Task properties

A task can include:

- Task title.
- Task notes.
- Due date.
- Priority: Low, Normal or High.
- Completion state.
- Important state.
- My Day membership.

## Views

| View | Records shown |
| --- | --- |
| My Day | Tasks added to the current day's list |
| Important | Tasks marked as important |
| Planned | Tasks with a due date |
| Tasks | Unfinished tasks |
| Completed | Finished tasks |

The Planned view uses the due-date field. Completing a task moves it into Completed; selecting its checkbox again there restores it to unfinished tasks.

## Data boundary

Task information is saved locally. Operating-system notifications, recurring reminders, shared task lists and cloud sync are not part of the current product scope.
