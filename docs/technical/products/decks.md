# Decks technical reference

<img class="technical-product-icon" src="../../assets/icons/decks.svg" alt="Brightdesk Decks application icon" width="80" height="80" loading="lazy">


Decks is Brightdesk's slide presentation workspace.

## Slide operations

The current editor includes:

- New slide.
- Duplicate slide.
- Delete slide.
- Title slide.
- Text slide.
- Slide Show for presenting the current slide sequence.

## Built-in themes

The current theme choices are **Lavender**, **Midnight** and **Paper**.

## File handling

| Operation | Format |
| --- | --- |
| Open | PPTX |
| Export | PPTX |

## Technical boundaries

A theme is a presentation style choice, not a guarantee that every external theme or slide object will transfer unchanged. Keep the original presentation if you need to preserve unsupported source-specific features.
