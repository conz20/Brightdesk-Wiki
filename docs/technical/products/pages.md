# Pages technical reference

Pages is Brightdesk's document editor for letters, reports and other formatted documents.

## Page layout model

The current layout controls include:

| Setting | Available values |
| --- | --- |
| Paper size | A4, US Letter, US Legal |
| Orientation | Portrait, Landscape |
| Margins | Normal, Narrow, Moderate, Wide |

## File handling

Pages is the route for DOCX, Markdown and HTML input.

| Operation | Format |
| --- | --- |
| Open | DOCX, Markdown, HTML |
| Export | DOCX, HTML |
| PDF output | Available through Suite Home → PDF |

The PDF route is presented in Suite Home rather than as a Pages export format in the current product reference.

## Technical boundaries

File compatibility is format-specific. Opening a supported document does not guarantee that every advanced feature from the originating editor is represented identically. Retain the original file when exact source fidelity is important.
