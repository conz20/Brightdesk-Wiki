# Brightdesk Pages: technical detail

[Read the everyday Pages guide](../../products/pages.html) for simple step-by-step instructions.

## Document editing model

Pages combines a writing area with document-level controls. Text formatting is applied to selected content through the Home tab. Paragraph tools include headings, bullets, numbering and quotes. Undo and Redo move through recent editing changes.

## Page setup

The current source describes three paper sizes: A4, US Letter and US Legal. Orientation can be Portrait or Landscape. Margin presets are Normal, Narrow, Moderate and Wide. These are named presets; do not assume that arbitrary custom page dimensions or margin measurements are available.

## Review and export

Word count and the spell-check setting are available from Review. The View controls include zoom and Focus mode. The PDF export path documented for the current interface is Home, then PDF in the Export group. Other output formats depend on the installed version and should be checked in its Export menu.

## Data and compatibility boundaries

Use Save project for Brightdesk project data and Open for supported existing project or document data. Pages is a core document editor, not a claim of complete word-processor parity. Macros, collaboration, advanced publishing layout and perfect round-trip conversion are not promised.
