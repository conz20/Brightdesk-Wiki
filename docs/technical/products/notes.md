# Notes technical reference

Notes is a lightweight workspace for capturing text, ideas and reminders.

## Content elements

The current editor supports inserting:

- Dates.
- Dividers.
- Checklist items.

The Clear note action includes a confirmation prompt before the note is cleared.

## File handling

| Operation | Formats |
| --- | --- |
| Open | Plain text |
| Export | Markdown, plain text |

## Data boundary

Notes content is saved locally. Export creates a separate file in the selected format.
