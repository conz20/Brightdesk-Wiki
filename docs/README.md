## Documentation promise

We distinguish what is implemented and verified from what is planned, proposed or still being tested. A picture of a proposed interface is not presented as a screenshot. A configured installer is not described as a tested release. When a guide depends on a particular version or operating system, the guide says so.

If a page cannot answer your question, use the repository's Issues page to request a guide or report an error: [Brightdesk Wiki issues](https://github.com/conz20/Brightdesk-Wiki/issues).

## For contributors

Read the [documentation standards](documentation-standards.md) and use the [article template](article-template.md) when adding a page. Keep customer instructions separate from developer notes. Link claims to the implementation, test or decision that supports them.
