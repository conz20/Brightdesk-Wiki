# How-to guides

This section contains task-based instructions. Each guide should answer one clear question and take the reader from the starting point to the expected result.

## Example guide titles

- Create your first document in Pages
- Add a formula in Sheets
- Start a presentation in Decks
- Create a local form and review its responses
- Filter a list to find a record
- Add a task to Planner
- Set a due date in To Do

These are planned guide topics, not confirmation that every step is already documented or verified. A guide is published as a complete procedure only after its steps have been checked against the relevant product build.

## Guide format

1. State what the reader will achieve.
2. List any requirements.
3. Give one action per numbered step.
4. Use the exact visible button or menu label.
5. Explain what the reader should see after each important action.
6. Explain how to undo or recover when relevant.
7. Record the product version and verification evidence.
