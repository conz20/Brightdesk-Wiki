## What each product page will contain

Each product guide is intended to answer:

1. What is this product for?
2. What can I currently do with it?
3. How do I complete common tasks?
4. Where is my work saved?
5. What should I do if something goes wrong?
6. Which features are planned or not yet available?

Feature lists and step-by-step instructions are added only when supported by the current product source or a passing test. Until then, a page may be marked as a starter page rather than pretending to be a complete user manual.
