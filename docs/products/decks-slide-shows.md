# Present a slide show in Brightdesk Decks

This guide covers the slide-show controls currently documented for Brightdesk Decks. It does not describe advanced presenter tools or effects that are not confirmed in the current product reference.

## Start from the slide you want

1. Open your presentation in Brightdesk Decks.
2. Select the slide where you want the presentation to begin.
3. Open **Slide Show**.
4. Choose **From current slide**.

**What you should see:** the presentation starts from the slide you selected.

## Move through the presentation

- Click the slide area to move forward.
- Use the arrow keys to move between slides.
- Press **Esc** to leave presentation mode and return to editing.

## If the presentation starts on the wrong slide

1. Press **Esc** to leave the slide show.
2. Select the slide you want to start from.
3. Open **Slide Show → From current slide** again.

## Current feature boundaries

The current Decks guide confirms starting a slide show from the selected slide, moving with clicks or arrow keys and leaving with **Esc**. Do not assume Presenter View, rehearsed timings, laser pointers, pen annotations, transitions, animation or embedded media are available unless a current Brightdesk release explicitly documents and verifies them.
